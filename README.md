# Sarashina Editor

CodexやClaudeとSarashina3が協力して、日本語の文章を推敲する非公式プラグインです。

専門用語や論旨、主張の強さはCodex・Claudeが確認し、語順やリズム、語感の候補をSarashina3が提案します。候補を原稿と照らし合わせ、必要なら具体的な指摘を返して再修正します。文章の自然さと内容の正確さを、別々に確かめるための仕組みです。

> このREADMEの日本語は、Sarashina Editorを使ってSarashina3と推敲しました。仕様と手順はCodexが照合しています。

## ダウンロード

[最新版の配布ファイル](https://github.com/KouyamaCreate/sarashina-editor/releases/latest)から、利用するアプリに合うものを選んでください。

| 利用先 | ファイル | 確認状況 |
| --- | --- | --- |
| Codex.app / ChatGPT.appのローカルCodex（Mac） | `sarashina-editor-macos-setup-0.1.3.zip` | 実チャットで動作確認済み |
| Claude.appの通常チャット | `sarashina-editor-0.1.0.mcpb` | パッケージ検証済み・実画面は未確認 |
| Codex CLI / Claude Code | `sarashina-editor-0.1.0.zip` | 共通サーバーを検証済み・Claude Codeでの実会話は未確認 |

アプリのWeb版やクラウド実行環境への導入には対応していません。プラグイン本体は0.1.0、Mac用セットアップは0.1.3です。

## Codex.app / ChatGPT.appに導入する

Apple Silicon Mac・macOS 12以降向けです。ターミナル操作やCodex CLIの導入は不要です。

1. 配布ZIPを展開し、`Sarashina Editor Setup.app` を開きます。
2. [公式コンソール](https://chat.sarashina.ai/dashboard/api-keys)で発行したAPIキーを、セットアップの入力欄に貼り付けます。
3. Node.jsが検出されていることを確認して「登録して保存」を押します。未検出の場合は、セットアップ内のリンクからNode.js 20.9以降を導入して開き直してください。
4. Codex / ChatGPTアプリを完全終了し、起動し直します。ウィンドウを閉じるだけでなく、⌘Qで終了してください。
5. ローカルの会話で「Sarashinaでこの文章を推敲して」と依頼します。

APIキーは後から入力することもできます。空欄のまま再登録しても、保存済みのキーは消えません。キーをチャットに貼る必要はありません。

セットアップは開発者IDによる署名・公証を行っていないため、macOSの設定によっては開けません。セキュリティ機能を一括で無効にせず、配布元と内容を確認してから利用してください。

既存の設定をバックアップし、個人用カタログへの登録とプラグインの有効化を行います。APIキーはこのMacの専用ファイルに保存します。詳しくは下の「データの扱い」を参照してください。

## Claude.appに導入する

1. 配布された `.mcpb` を開きます。開けない場合は、Claudeの拡張機能の設定からファイルを選択してください。
2. 拡張の設定画面でSarashinaのAPIキーを入力し、有効化します。
3. 新しいチャットを開始し、Sarashinaによる推敲を依頼します。

追加のnpmインストールは必要ありません。組織の設定によっては、ローカル拡張を導入できない場合があります。Claude.appのCode機能やClaude Code CLIについては、[CLI向け導入手順](docs/installation.md)を参照してください。

## 使い方

文章とともに、読者層・用途・残したい語り口を伝えると、候補の比較がしやすくなります。

> Sarashinaで次の論文要旨を推敲して。読者はこの分野の研究者。専門用語、引用、主張の強さは変えず、常体で論理が自然につながるようにして。

> このメールをSarashinaと整えて。長年付き合いのある相手なので、礼儀は保ちつつ堅苦しくしない。依頼内容と期限は変えない。

> 2つ目の案が近い。ただし最後の文は説明しすぎなので、事実は足さずに短くして。

## 推敲の流れ

1. Codex・Claudeが原稿の主張、根拠、専門用語、文体の方針を整理します。
2. Sarashina3が最大2つの候補を提案します。
3. 文字列・数値などの機械検査に加え、Codex・Claudeが意味と読みやすさを原稿と比較します。
4. 修正が必要な場合、前の候補と具体的な指摘をSarashina3に返します。最大3往復まで可能です。
5. 審査を通過した候補を返します。改善が見られない場合は、原稿を採用します。

機械検査もモデルによる審査も、意味の同一性を保証するものではありません。公開する文章の事実や引用は、人による最終確認が必要です。1回の編集対象は最大12,000文字です。

## データの扱い

原稿、編集方針、用語、参考文体と、再修正時の前候補・指摘をSB Intuitionsの公式APIへ送ります。送信先は `https://api.sarashina.ai/v1/chat/completions` に固定しています。プロジェクトファイルや会話全体の自動収集、ファイルの自動書き換え、投稿は行いません。

原稿と候補はローカルサーバーのメモリに保持し、再起動または2時間の非活動で失効します。Codex・Claudeの会話履歴やAPI提供元での保存とは別です。

Mac用セットアップとCLI版のAPIキーは `~/.config/sarashina-editor/config.json` に保存します。所有者のみ読み書きできる権限ですが、暗号化はしていません。Claude.appの拡張版は、拡張の機密設定を使います。配布ファイルにAPIキーは含まれません。

API提供元の入出力の保存・学習利用については、[利用規約](https://sarashina.ai/terms)と[プライバシーポリシー](https://www.sbintuitions.co.jp/privacy-policy/)を確認してください。機密情報や未公開原稿は、適用される契約条件を確認してから送信してください。

## 呼び出せないとき

「Sarashina Editorの `sarashina_status` を実行して」と依頼してください。`configured: true` はキーが設定されていることを示します。生成APIへの疎通確認ではありません。

スキルだけ読めてツールを呼べない場合は、最新版のセットアップで再登録し、アプリを完全終了して開き直してください。キーは空欄で再登録すれば保持されます。古いセットアップには、サーバーの起動パスが正しく解決されない不具合がありました。
